# Security

Report suspected vulnerabilities privately to the repository owner. Do not include secrets, private Candidate App source, hidden certification inputs, or exploit material in public issue content.

The Test Suite treats supplied CanApp paths and network targets as untrusted inputs. The RESPECT-ification Kit keeps private Prep information owner-local and rejects secret-bearing, escaping, or unsafe paths.

This repository does not yet publish a dedicated security-reporting address.
Until the owner supplies one, do not invent or document an unofficial public
channel. Coordinate privately with the known repository owner and disclose
only the minimum information needed to establish the issue.
