# Harness

The Matrix-driven RESPECT Compatible Test Suite is the `respect_compat` package. The source-local RESPECT-ification Kit is the `respect_ification` package.

Private tests must consume an immutable commit of this repository rather than copying either package.

The native Android runtime harness is a suite-owned xAPI companion, a separate bounded-gesture injector, and a Python Android Debug Bridge controller. Its joint build receipt, health control, target binding, bounded scenario parser, catalog-derived launch construction, activity binding, gesture receipts, and direct event projection prevent Candidate App-authored result data from entering the trusted runtime path. Generic normalized strokes support tracing, drawing, dragging, and handwriting while lesson selectors and geometry remain owner-local. The harness remains unaware of proprietary lesson formats.
