# RESPECT Compatible Profile Provenance

The historical `RESPECT Native Android Compatible v0.1` profile is preserved byte-for-byte under `respect_compat` package data as a non-canonical runtime profile. It records JiMS-authored clean-room requirement metadata derived from observed active RESPECT code, tests, fixtures, and repository metadata; it does not copy RESPECT implementation code or fixture text governed by the GNU Affero General Public License version 3.0.

The canonical Matrix is a distinct resource and remains the sole compatibility-requirements authority.
