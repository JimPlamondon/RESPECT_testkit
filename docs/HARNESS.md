# Harness

The Matrix-driven RESPECT Compatible Test Suite is the `respect_compat` package. The source-local RESPECT-ification Kit is the `respect_ification` package.

Private tests must consume an immutable commit of this repository rather than copying either package.

The native Android runtime harness is a suite-owned companion Android application plus a Python Android Debug Bridge controller. Its build receipt, health control, target binding, bounded scenario parser, and direct event projection prevent Candidate App-authored result data from entering the trusted runtime path.
